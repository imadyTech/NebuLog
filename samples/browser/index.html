Sending logs from a browser

This page posts an OpenTelemetry ExportLogsServiceRequest as OTLP/JSON to /v1/logs. It is served from the same origin as the API, so no CORS is involved; a page on another origin would need its origin added to NebuLog__Cors__AllowedOrigins.

The key stays in this tab and is never stored. Create one on the dashboard's API keys page.
